# =============================================================================
# Setup instructions — Windows VM (NVIDIA T4, CUDA 12.1)
# Copy-paste each block into PowerShell in order.
# =============================================================================
#
# --- 1. Clone the repo (skip if already done) --------------------------------
#
#   git clone https://github.com/<your-username>/umc_thesis.git
#   cd umc_thesis
#
# --- 2. Create and activate a virtual environment ----------------------------
#
#   python -m venv .venv
#   .venv\Scripts\activate
#
# --- 3. Install PyTorch with CUDA 12.1 (T4 GPU) ------------------------------
#
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
#
# --- 4. Install remaining dependencies ---------------------------------------
#
#   pip install -r requirements.txt
#
# --- 5. Verify GPU is detected -----------------------------------------------
#
#   python -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0))"
#
#   Expected output:
#     True
#     Tesla T4
#
# --- 6. Place the data -------------------------------------------------------
#
#   Copy your data into the repo so it matches these paths:
#     umc_thesis/data/data/Data_MOCKI_analyse_per_foto.xlsx
#     umc_thesis/data/images/          (stone photos)
#     umc_thesis/data/processed/       (created automatically by 01_prepare_data.py)
#
# --- 7. Run the pipeline -----------------------------------------------------
#
#   python scripts/01_prepare_data.py
#   python scripts/02_prepare_images.py
#   python scripts/05_train_binary.py          # Model A: pure/mixed
#   python scripts/05_train_composition.py     # Model B: composition regression
#   python scripts/05_train_multiclass.py      # Model C: dominant component
#   python scripts/06_evaluate_binary.py
#   python scripts/06_evaluate_composition.py
#   python scripts/06_evaluate_multiclass.py
#   python scripts/statistical_tests.py        # cross-model significance tests
#
# --- Note on num_workers (Windows only) -------------------------------------
#
#   If you get a multiprocessing error during training, open config.yaml and set:
#     num_workers: 0
#   under both `training:`, `training_composition:`, and `training_multiclass:`.
#
# =============================================================================
