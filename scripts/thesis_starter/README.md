compositional regression model of kidney stone FTIR profiles.

## Pipeline

Run scripts in order. The numbered prefix enforces the order explicitly.

```bash
# 1. Prepare the data (Excel → CSVs with labels applied)
python scripts/01_data_prep.py

# 2. Generate exploratory figures
python scripts/02_eda.py

# 3. Verify dataset splits (stone-level, stratified)
python scripts/03_dataset.py

# 4. Verify model construction (downloads ResNet50 weights on first run)
python scripts/04_model.py

# 5. Train (all folds)
python scripts/05_train.py

# Useful 05_train.py flags:
python scripts/05_train.py --fold 0      # just fold 0 (for iterating)
python scripts/05_train.py --quick       # 2 epochs/phase (smoke test)
```

Outputs land in `outputs/`:
- `outputs/checkpoints/fold_<i>/best.pt` — best checkpoint per fold
- `outputs/checkpoints/fold_<i>/history.csv` — per-epoch metrics
- `outputs/checkpoints/fold_<i>/summary.json` — best-epoch summary
- `outputs/logs/cv_summary.csv` — cross-fold mean ± std
- `outputs/figures/*.png` — EDA figures

## Key decisions locked in

- **Binary task:** pure vs mixed at stone level
- **Purity threshold:** configurable (default 90%, following Kim 2022)
- **Excluded stones:** S168 (TWM, no composition), S301 (empty)
- **OTH remapping** based on FTIR sub-identification:
  - Na-H-urate hydrate (16), Monoammonium urate (7), Uric acid dihydrate (2) → UA
  - Ca-Mg phosphate (3) → CHP
  - Newberyite (1) → MAP
  - Calcite (9), Protein/albumin (10), Xanthine (5) → stay OTH
- **Splitting:** stone-level stratified 5-fold CV (prevents leakage between
  the 3 photos of the same stone)
- **Model:** ResNet50 pretrained on ImageNet, swappable via `config.yaml`
